Exercise 2: Addition and Scalar Multiplication
1. Problem Statement

Given the matrices

A = [[1, 2], [-1, 3]]

B = [[4, -2], [0, 5]]

Compute A + B, A - B, and 3A - 2B. Explain why matrix addition is possible only for matrices of the same size.

2. Theoretical Background and Concepts

Matrices of the same size can be added or subtracted by adding or subtracting their corresponding entries.

Scalar multiplication means multiplying every entry of a matrix by the same number.

3. Detailed Step-by-Step Solution

Step 1: Calculate A + B.

Add corresponding entries:

A + B = [[1 + 4, 2 + (-2)], [-1 + 0, 3 + 5]]

Therefore,

A + B = [[5, 0], [-1, 8]]

Step 2: Calculate A - B.

Subtract corresponding entries:

A - B = [[1 - 4, 2 - (-2)], [-1 - 0, 3 - 5]]

Therefore,

A - B = [[-3, 4], [-1, -2]]

Step 3: Calculate 3A - 2B.

First, multiply each entry of A by 3:

3A = [[3, 6], [-3, 9]]

Then multiply each entry of B by 2:

2B = [[8, -4], [0, 10]]

Subtract the matrices:

3A - 2B = [[3 - 8, 6 - (-4)], [-3 - 0, 9 - 10]]

Therefore,

3A - 2B = [[-5, 10], [-3, -1]]

Step 4: Explain the size requirement.

Matrix addition is possible only when both matrices have the same number of rows and columns. This is necessary because every entry in one matrix must have a corresponding entry in the other matrix.

Here, both A and B are 2 × 2 matrices, so all the required operations are defined.

4. Verification and Consistency Checks

For A + B, adding the corresponding entries gives [[5, 0], [-1, 8]].

For A - B, subtracting the corresponding entries gives [[-3, 4], [-1, -2]].

For 3A - 2B, the scalar multiples are 3A = [[3, 6], [-3, 9]] and 2B = [[8, -4], [0, 10]]. Their difference is [[-5, 10], [-3, -1]].

All results follow the entry-by-entry rules for matrix addition and subtraction.

Final Answers

A + B = [[5, 0], [-1, 8]]

A - B = [[-3, 4], [-1, -2]]

3A - 2B = [[-5, 10], [-3, -1]]

Matrix addition is possible only for matrices of the same size.
