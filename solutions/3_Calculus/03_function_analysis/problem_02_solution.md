
# Problem 2. A Parabola from the Perspective of the Derivative

Given the function:

\[
f(x)=x^2-4x+1
\]

Find the minimum using the derivative. Compare the result with the vertex form and explain why both approaches lead to the same point.

## 1. Find the Derivative

Differentiate the function:

\[
f'(x)=2x-4
\]

Set the derivative equal to zero:

\[
2x-4=0
\]

\[
2x=4
\]

\[
x=2
\]

The critical point occurs at \(x=2\).

## 2. Determine the Minimum

Calculate the second derivative:

\[
f''(x)=2
\]

Since

\[
f''(x)=2>0
\]

the function is concave upward, so \(x=2\) gives a minimum.

Find the corresponding \(y\)-coordinate:

\[
f(2)=2^2-4(2)+1
\]

\[
f(2)=4-8+1=-3
\]

Therefore, the minimum point is

\[
\boxed{(2,-3)}
\]

The minimum value is \(-3\).

## 3. Find the Vertex Form

Complete the square:

\[
f(x)=x^2-4x+1
\]

\[
f(x)=(x^2-4x+4)-4+1
\]

\[
f(x)=(x-2)^2-3
\]

The vertex form is

\[
\boxed{f(x)=(x-2)^2-3}
\]

Since \((x-2)^2\geq0\), the smallest possible value occurs when \(x=2\).

Thus,

\[
f(2)=0-3=-3
\]

The vertex is \((2,-3)\).

## 4. Compare the Two Methods

**Derivative method:**

The derivative identifies the critical point \(x=2\), and the second derivative confirms that it is a minimum.

**Vertex form method:**

Completing the square shows directly that the smallest value occurs at \(x=2\).

Both methods give the same point because they describe the same parabola. The derivative finds where the slope is zero, while the vertex form reveals the minimum algebraically.

## Final Answers

1. First derivative: \(f'(x)=2x-4\).
2. Critical point: \(x=2\).
3. Minimum value: \(-3\).
4. Minimum point: \(\boxed{(2,-3)}\).
5. Vertex form: \(\boxed{f(x)=(x-2)^2-3}\).
6. Both methods lead to the same vertex because the parabola reaches its minimum where its derivative is zero.
